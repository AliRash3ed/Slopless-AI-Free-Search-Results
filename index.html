Download and Install

Get Slopless running on your browser in under 60 seconds.

Download Slopless Extension (.zip)
1

Download the ZIP File

Click the purple "Download" button above. A .zip file will be saved to your computer. Extract or unzip this file to a folder you will remember (like Desktop or Documents).

2

Open Your Browser's Extension Page

For Chrome: Type chrome://extensions in your address bar and press Enter. For Edge: Type edge://extensions. For Brave: Type brave://extensions.

3

Enable Developer Mode

Find the "Developer mode" toggle in the top right corner of the extensions page. Turn it ON. This allows your browser to load extensions from local files.

4

Load the Extension

Click "Load unpacked" in the top left. Navigate to the folder where you extracted the ZIP file. Select the folder and click "Open." Slopless will appear in your extensions list.

5

Pin It (Optional)

Click the puzzle icon in the top right of your browser toolbar. Find "Slopless" in the dropdown list. Click the pin icon to keep Slopless visible at all times for quick access.
